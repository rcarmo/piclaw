Plannotator — Como integrar no frontend?

Escolhe a abordagem de integração que faz mais sentido

A

Novo Pane no Tab Strip

Abre numa tab ao lado do editor, como os outros viewers. Via slash command /plannotate ou botão na timeline. Persiste enquanto aberto, pode ser pop-out para janela separada.

Prós

  • Segue padrão existente
  • Pop-out para janela dedicada
  • Tab reutilizável

Contras

  • Ocupa espaço do editor
  • Menos imediato para review rápido
B

Painel Lateral (estilo BTW)

Overlay lateral que aparece ao lado da timeline quando invocado. Não ocupa espaço do editor. Fecha com Escape ou botão. Ideal para review inline durante uma conversa.

Prós

  • Não interrompe o fluxo
  • Sempre visível com o chat
  • Pattern já testado (BTW)

Contras

  • Espaço limitado em mobile
  • Sem pop-out
C

Híbrido: Painel + Tab

Começa como painel lateral para review rápido. Botão "Abrir em Tab" expande para pane dedicado com funcionalidade completa (diff, anotações, exportar).

Prós

  • Melhor dos dois mundos
  • Adaptável ao contexto
  • Escalável para funcionalidades futuras

Contras

  • Mais código a implementar
  • Dois modos a manter
